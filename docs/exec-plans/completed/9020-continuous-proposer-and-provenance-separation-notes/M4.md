# M4 — Escape sampler tranche split

Implementation notes. See `docs/conventions/implementation-notes.md`.

### [plan-confirmed] 2026-08-27T10:15:00Z — M4 complete: tranche split with type-enforced random-only estimator

`src/argus/core/escape_sampler.py` lands `AutoPassedCall`, `RandomTranche`, `PrioritizedTranche`, `split_tranches`, and `compute_escape_rate`. Tests pass 5/5 (27/27 across 9020). The random tranche is a hash partition of `call_id` (decorrelated from `proposed_score`, deterministic), sized `max(floor, round(fraction·n))` capped at n. Verified adversarially: the random-tranche rate (0.108, true 0.10) differs from the prioritized-tranche miss fraction (0.092), and the type gate rejects the prioritized tranche — so the exclusion guards a measured bias, not a hypothetical one.

### [discovery] 2026-08-27T10:10:00Z — decorrelation without an RNG, via a hash partition

D22 wants the random tranche "decorrelated from the proposer signal". A seeded RNG would achieve that only in expectation and would add seed-state to thread through replay. Sorting by `sha256(call_id)` and taking the smallest keys is decorrelated by construction (the hash is independent of `proposed_score`) and byte-stable on replay — no clock, no RNG. The floor is applied as `max(floor, ...)` capped at n, so it can raise the sample size but never invent calls that do not exist.

### [deviation] 2026-08-27T10:05:00Z — 9002 M5.5 owns compute_escape_rate; provisional estimator here, config as args

- **What the plan said:** enforcing random-only "means a signature change in a 9002-owned file", so M4 waits on 9002.
- **What the code revealed:** 9002 M5.5 and its `compute_escape_rate` are unstarted, and the split ratio and floor are config (Q3), whose layer is sensitive and not in M4's writes.
- **Conservative choice:** implement the split and a compatible `compute_escape_rate` in `escape_sampler.py`, enforcing random-only by a distinct `RandomTranche` type rather than by changing a 9002 signature. The ratio and floor are function arguments with provisional defaults (0.5, 0), not config-layer values.
- **Revisit:** when 9002 M5.5 lands, reconcile this estimator with its `compute_escape_rate` (keep the type gate), and when Q3 lands config, move the ratio and floor there. Tracked against Q3 and the 9002 cross-plan dependency.

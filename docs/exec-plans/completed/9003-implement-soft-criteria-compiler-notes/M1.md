### [discovery] — S5 needs the combined-utterance clause, not substring overlap

The naive "exclusion pattern inside an inclusion pattern" reading does not
flag the test's data: exclusions 您可以选择/随您方便 share no substring with
inclusions 建议/推荐. The test only passes via the patch-2 Surprise 5 clause:
any utterance containing both an inclusion and an exclusion (e.g. 我建议您可
以选择办理移动证书) is a positive case the naive AND-NOT rejects, so every
non-empty exclusion set on an inclusion-bearing signal warns (warn-level,
non-blocking).

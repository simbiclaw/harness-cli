## Adversarial Edge Case Analysis

### Edge Case 1: PEV_ARBITER env var detection bypass
**Probe:** Test `_is_arbiter()` with values like `"true "` (trailing space), `" true"` (leading space), `"yes"`, `"1"`, `"t"`.

**Result:** Three categories:
- `true`/`TRUE`/`True` — **PASS** (case-insensitive detection works)
- `"true "` / `" true"` — **BYPASS** (whitespace not stripped; `"true "` != `"true"`)
- `"yes"` / `"1"` / `"t"` — **BYPASS** (only exact `"true"` matches)

**Root cause:** `_is_arbiter()` does `os.environ.get("PEV_ARBITER", "").lower() == "true"` without stripping whitespace.

**Classification:** Mechanical — low severity. The env var is set programmatically by the tmux script, so trailing space is unlikely in practice. But it's a fragility. Fix: add `.strip()` before the comparison.

### Edge Case 2: Guard 6 bypass via git cherry-pick
**Probe:** Test `COMMIT_LIKE_RE` against `git cherry-pick`, `git rebase --continue`, `git push`.

**Result:** 
- `git commit` / `git merge` — **BLOCKED** (correct)
- `git cherry-pick abc123` — **BYPASS** (not matched by COMMIT_LIKE_RE)
- `git rebase --continue` — **BYPASS** (not matched)
- `git push` — **BYPASS** (not matched)

**Root cause:** `COMMIT_LIKE_RE = re.compile(r"(?:^|;|&&|\|\|)\s*git\s+(commit|merge)\b")` explicitly only matches `commit` and `merge`. `cherry-pick` is excluded.

**Classification:** Mechanical — medium severity. `cherry-pick` creates new commits just like `commit`. A non-arbiter subagent (P/E/V) could cherry-pick to introduce commits, violating Guard 6's intent of "only the Arbiter commits." Fix: add `cherry-pick` to the COMMIT_LIKE_RE alternation.

### Edge Case 3: `_is_arbiter_safe_path` — conventions directory not safe
**Probe:** Test `_is_arbiter_safe_path()` with `str(REPO_ROOT / "docs/conventions")` (bare directory).

**Result:** Returns **False**. The function checks `rel.startswith("docs/conventions/")` (trailing slash), so the bare directory `docs/conventions` does not match. Files inside the directory (e.g., `docs/conventions/pev-loop.md`) are correctly safe.

**Classification:** Semantic — very low severity. Editing a bare directory is not a realistic tool operation. Files inside conventions are correctly allowed.

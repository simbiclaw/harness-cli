📚 Lessons Learned
The V→P→E feedback arc works — M1 proved it.

Two REJECTED verdicts flowed back to P, who updated the contract, handed to E, who repaired. The third iteration CONFIRMED. This is the loop closing in practice.

↑ Promoted to structural test (loop closure)
Commit authority must be enforced before the first milestone.

M1's P/E commit conflict showed that allowing agents to commit independently creates divergence. The rule "only the Arbiter commits" with RED→GREEN two-commit model prevents this. Hook Guard 6 blocks non-Arbiter commits.

Persistent V accumulates confirmation bias.

After confirming 6 consecutive milestones, V's adversarial stance weakened. The adversarial-clean dispatch rule strips V's context per verification to restore skepticism.

↑ Promotion candidate: structural test → hook (enforce clean dispatch)
Harness improvements are themselves plan output.

14 structural tests, 2 hook guards, and major documentation revisions were created DURING the 9006 execution — not planned in advance. The harness detected its own gaps and self-corrected. This is the Agentic Harness Optimization loop (paper §3.5) in action.

Behavioral tests must be mandated, not assumed.

M0 shipped with zero behavioral tests because nobody checked. The behavioral coverage mandate (every milestone must have an Acceptance Test or explicit waiver) closes this gap structurally.

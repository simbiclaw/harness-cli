📚 Lessons Learned
对抗收敛模式

每一轮 B 都找到相邻变异家族(字符串布尔→defer 子串→大小写→格式字符;连接词 7 层;camelCase→词内锚定)。RED 测试逐条封死,残差显式裁决——收敛而非无限追逐。

测试即契约

RED 测试钉死 API 形状与不变量;跨模块联动(M1 校验器 ↔ M4 播种 ↔ M5 绑定)由测试矩阵保证。33+ 对抗发现全部先写红测试再修复。

沙箱覆盖层必须非沙箱验证

Bash 沙箱隐藏真实 FS 状态——实施与验证一律 dangerouslyDisableSandbox,编排者在翻转前亲自复核。

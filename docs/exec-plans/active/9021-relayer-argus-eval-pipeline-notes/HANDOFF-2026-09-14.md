test-side comparison rewritten to actually check them:
1. Field alias (`Field(alias=...)`) silently changes the wire key — invisible to old floor.
2. `FieldInfo.metadata` constraints (`ge=`, `max_length=`, etc.) added or removed — invisible.
3. `model_config` changes: `extra="forbid"`, `frozen=True`, `str_to_lower=True`, `str_strip_whitespace=True` — none recorded.
4. A `@field_validator` or `@model_validator` added to a field (e.g. one that zeroes `Verdict.score`, or clears `Verdict.evidence`) — validators not recorded at all.

Enum base class changed, e.g. `(str, Enum)` → `(Enum)` — breaks `TurnFlag.NORMAL == "NORMAL"` and JSON serialization at real call sites (`simbiclaw/sim@0c2cccd core/atomizer.py:81,85`, `core/question_generator.py:86,147,206,210`, `core/intent_inferrer.py:45,49,53`) — old floor only recorded name→value, not base class.
6. Enum member order changed — old floor's comparison used dict equality (order-insensitive).
7. Provenance not verified — `UPSTREAM_COMMIT` was a bare literal nothing checked against git; a fixture could be regenerated from any directory and still claim `0c2cccd`. Round 4's builder fixes this (verifies the SHA and diffs the imported file byte-for-byte against that commit) — **this part is done and working**, just needs the test to actually assert on `source`/provenance fields if it doesn't already.

Group B — reported by the *second* verifier (round 2, on top of round-1's
fix), **NOT yet addressed by round 4's WIP builder at all** — these need new
work, not just wiring up the test side:
8. **Empty-container freshness gap.** `default_key`/`_default_key`'s freshness
   check (`if not produced: return repr(produced)`) returns *before* sampling
   for empty containers — so a `default_factory` closing over a shared
   module-level `[]` or `{}` (e.g. two fields both doing
   `Field(default_factory=lambda: _SHARED_LIST)`) passes green, and two
   `Session()` instances then share one mutable `metadata`/`turns` object —
   demonstrated: `a.metadata["order_id"]="A-123"` leaks into `b.metadata`.
   This is the exact defect class round 1 fixed, on the one branch (empty
   containers) the fix didn't cover. **Fix needs a per-instance identity
   probe** (call the factory twice, compare `id()` of the two results) that
   runs regardless of whether the produced value is falsy.
9. **Freshness sampler is a weak proxy for entropy.** Three samples classify
   "not constant" — but `lambda: str(uuid.uuid4())[:1]` differs across 3 draws
   (so keys `fresh`) while producing only 16 distinct values across 2000
   calls; and a factory that's fresh for its first ~50 calls then goes
   constant keys as `fresh` because the suite only calls it ~22 times.
   `session_id` is what `QAReport` and the M21 replay record key on
   (`core/aggregator.py:98`), so near-collision entropy matters, not just
   "changes sometimes." Needs either a much larger sample with a documented
   floor (e.g. "N draws must produce N distinct values"), or accept this is
   a known limit and say so explicitly in a comment rather than implying the
   check is stronger than it is.
10. **Extra classes are invisible.** The comparison iterates the *snapshot*
    (upstream's model/enum set) and checks the port has everything upstream
    has — but never checks the port does NOT have classes upstream lacks.
    `class SmuggledScore(BaseModel): proposed_score: float = 0.0` added to
    `pipeline.py` passes green today. `proposed_score` is precisely the name
    I5 and I7 (see CLAUDE.md) exist to keep out of this contract, so this
    matters beyond generic schema fidelity. Fix: compare model/enum name sets
    as **exact sets** (`==`, not "upstream ⊆ port"), and retire the
    hand-written `len(SNAP["models"]) == 16` count assertion at
    `tests/test_schemas.py:217-218` in favor of that — a count is exactly the
    "hand-written table" failure shape round 1 was rejected for, relocated
    from names to a count.
11. **Enum aliases skipped.** `{m.name: m.value for m in obj}` (iterating an
    enum) skips aliased members. Use `obj.__members__` if alias-safety
    matters (probably low priority — note it, fix if cheap, don't block on
    it).

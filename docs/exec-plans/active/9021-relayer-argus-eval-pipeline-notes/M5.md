# M5 — Port B's schemas into `types/`

Rejected a **third** time, 2026-09-13 — by a defect the main session found while
briefing subagent B. Repaired at the commit carrying this note. No checkbox flip
until a CONFIRMED verdict from subagent B is recorded in the Decision Log.

### [deviation] 2026-09-12 — First attempt rewrote the contract it was meant to copy

- **What the plan said:** Port `models/schemas.py` faithfully.
- **What the code revealed:** The first attempt invented `TurnFlag.UNCERTAIN`
  and `STUTTER`, deleted the live-emitted `ASR_ERROR` and `ROLE_SWAPPED`,
  relaxed three required fields to optional, and added `data_dependency` and
  `scorable` fields upstream does not have. `hasattr()` guards written by the
  same author masked all of it.
- **Conservative choice:** Redone as a single module mirroring upstream
  class-for-class, with no `model_config` changes so that upstream's
  `extra="ignore"` parity is preserved rather than silently improved.
- **Revisit:** The port's `extra="ignore"` means unknown keyword arguments are
  dropped without error. M6 relied on this being true and put the I2 anchor in
  its own type rather than smuggling fields through.

### [deviation] 2026-09-12 — A hand-written oracle guards only what someone remembered

- **What the plan said:** An acceptance test comparing the port to upstream.
- **What the code revealed:** The second attempt's tables happened to be
  correct but the approach was unsound — a model omitted from *both* the port
  and the table is undetectable, and the tables guarded field *names* only, so
  a changed default, a widened annotation or a relaxed requirement all passed
  green. Flipping `RubricItem.weight`'s default from 1.0 to 2.0 doubles every
  unweighted row's contribution to the shipped score and the test said nothing.
- **Conservative choice:** Stop transcribing. `scripts/build_schema_snapshot.py`
  imports the upstream module and records every field's requiredness, realized
  default and annotation, declaration order, the full model set, and every
  enum's complete name→value map. Completeness becomes a property of the
  snapshot rather than of anyone's diligence.
- **Revisit:** A diff in the snapshot is an on-disk format change (Tier C) and
  needs a steering entry, not a regenerate-and-move-on.

### [discovery] 2026-09-12 — `argus.types` now holds two `RubricItem` classes

`types/pipeline.py` and `types/compiler_schemas.py` both define one. They are
different contracts — upstream's scoring sheet and 9003's authoring schema —
and the collision is recorded in the port's docstring rather than resolved by
renaming, which would make the port unfaithful.

### [deviation] 2026-09-13 — The generated oracle had one blind spot, and it was reachable

- **What the plan said:** Generating the oracle from the upstream module makes
  completeness a property of the snapshot rather than of anyone's diligence.
  Mostly true — and it survived eight mutation classes — but not complete.
- **What the code revealed:** A `default_factory`'s value cannot be snapshotted;
  a uuid would never match twice. So `default_key` recorded it by *type*:
  `<factory:str>`. That made `lambda: "FIXED"` and
  `lambda: str(uuid.uuid4())[:8]` the same string to the comparison. Replacing
  the port's `Session.session_id` factory with a constant left all 23 tests
  green while every `Session` in the process shared one id. `session_id` is what
  `QAReport` keys on (`simbiclaw/sim@0c2cccd core/aggregator.py:98`) and what
  M21's replay record carries, so two different calls would have been
  indistinguishable in storage. Demonstrated, not argued: mutation applied in a
  scratch copy, suite green, two fresh `Session()` objects compared equal.
- **Conservative choice:** Put the property the type cannot carry *into the
  oracle* rather than into a bespoke assertion — the key is now
  `<factory:str:fresh>` or `<factory:str:constant>`, classified by sampling the
  factory three times. Snapshot regenerated from upstream. A named regression
  test pins the encoding directly, because the encoder is shared by the script
  and the comparison and a regression there would move both sides together and
  cancel out.
- **Revisit:** If upstream ever adds a factory that is legitimately constant,
  this test fails and a human decides. That is the intended behaviour — a
  constant factory is a contract change, not a detail.

### [discovery] 2026-09-13 — Three rejections, one shape

Every one of M5's three rejections was the same failure: a check that passed for
a reason other than the property it named. Hand-written tables guarded names
while defaults drifted; a generated oracle guarded types while behaviour
drifted. The lesson that generalises is not "generate the oracle" but "ask what
the check *cannot* see, then put that in the key."

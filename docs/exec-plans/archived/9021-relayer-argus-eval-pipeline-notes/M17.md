### [deviation] 2026-09-13 — The correlated class was not missing; only the runtime aggregator was

- **What the plan said:** "The correlated class has no counterpart in B and must
  be invented… This is the hardest of the three inventions."
- **What the code revealed:** True of upstream — its aggregator sums
  `v.score * v.weight` with no notion of where a verdict's error came from
  (`simbiclaw/sim@0c2cccd core/aggregator.py:52-56`) — but false of this
  repository. 9003 landed the class on the authoring side:
  `src/argus/core/compiler/classify.py:43-58` classifies an exemplar/case match
  as `"correlated"`, and `src/argus/core/compiler/agreement.py:36-46` already
  holds `_W_C = 0.4` with the same PROVISIONAL note. M17 invented the runtime
  aggregator, not the class.
- **Conservative choice:** Did **not** import `_W_C` from the 9003 compiler — a
  compiler private is not a runtime contract, and `core.compiler` is a separate
  concern. The constant therefore exists in two places, which is new debt.
- **Revisit:** M22, whose binding constraint is that no verdict-altering value
  lives as a hardcoded constant. Both copies collapse into one config key there.

### [deviation] 2026-09-13 — Stricter than the I6 table, deliberately

- **What the plan said:** CLAUDE.md scopes the redundant class to "another
  model-judged text criterion **on the same span**".
- **What the code revealed:** That leaves a model-judged text signal pointing
  *elsewhere* unclassified, and the two available classifications are both
  wrong: independent is over-confidence, correlated is Argus-vs-Argus voting by
  another name (§6.4).
- **Conservative choice:** Every model-judged text signal weighs 0.0 wherever
  it points — on-span it is redundant (D5), off-span it is discarded as a
  non-corroborator (co-location, D3). Strictly more conservative than the
  table, never looser. Spans compare by overlap rather than equality, so
  widening a span by one character does not escape the redundant class.
- **Revisit:** If a measured W_C ever makes a sub-anchor strength meaningful,
  revisit whether off-span model text deserves a class of its own.

### [human-todo] 2026-09-13 — W_C = 0.4 is unmeasured and there is nowhere to file the debt

The repository keeps no technical-debt register. The debt is stated in the
module docstring and repeated inline at the constant: 0.4 is not measured, the
correct value is `1 − corr(matcher_error, proposer_error)` on a human-labelled
sample of referent matches, `Confidence: low`. Until that sample exists, every
number this module returns for a correlated-only finding is a placeholder that
happens to be conservative. The same human-labelled sample settles
`CLEAR_THRESHOLD`, which is currently a transcription of CLAUDE.md's
"an independent corroborating anchor can clear this" priced at I6's 1.0.
